# Self-Healing Microservices Platform

## Overview

This project aims to build a microservices application with an automated deployment workflow and basic service monitoring.

The goal is to understand how containerization, CI/CD, infrastructure automation, and monitoring work together in a DevOps environment.

## Planned Technologies

* Linux
* Docker and Docker Compose
* Git and GitHub
* GitHub Actions
* Ansible
* Prometheus
* Grafana

## Project Status

Currently under development.

The application, deployment pipeline, monitoring setup, and recovery mechanisms will be implemented and tested incrementally.

## Learning Objectives

* Containerize application services.
* Automate build and deployment workflows.
* Manage configuration using Ansible.
* Monitor application health and performance.
* Test service failure and recovery scenarios.
